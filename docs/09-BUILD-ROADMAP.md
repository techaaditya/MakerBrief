# Milestone plan

## A. Provider evidence

Deliver one successful live transaction with original/reference/output images held with appropriate permission, sanitized metadata, actual unit debit and a maker's detail review. Stop and narrow unsupported garment categories if output quality is unreliable.

## B. Real commissioning workflow

Deliver a maker-sourced catalog, buyer specification, maker-reviewed details, quote and exact-version approval. Changing a visual detail must either receive a new truthful reference or be marked conceptual until the maker supplies one.

## C. Shared collaboration

Deliver real identities, role-specific review links and a transactional database. Concurrent buyer and maker edits must produce a conflict instead of silently replacing work. Retain all accepted production versions.

## D. Evidence and presentation

Deliver a permissioned recorded result, public sample path, evaluated workflow, deployment and a short demo showing a meaningful change. Include both failures and successful examples in your evidence notes.

## E. Product validation

Ask a willing maker to complete an actual sample brief and a buyer to explain the agreement. Fix the largest misunderstanding. Measure the same task again. Record sample size and actual task outcomes, not speculative revenue or return reduction.

Completion gates are behavior-based. Generating a lot of code does not establish a complete product. Use the tests and live evidence to decide which claims can appear in the submission.
