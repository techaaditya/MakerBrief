# Demonstration storyboard

Target about 2 minutes 40 seconds. Show the functioning app and name the YouCam API used.

0:00–0:15: A buyer wants a custom outfit, but a beautiful inspiration image leaves the maker guessing. Introduce MakerBrief.

0:15–0:45: Show a real maker garment and authorized personal YouCam preview. Clearly identify source, reference and generated result. If waiting is shortened, label the edit.

0:45–1:15: Open the maker's detail review. Identify a discrepancy or unresolved construction detail. Show the actual detail evidence and the confirmed production specification.

1:15–1:50: Issue a quote, record agreement, then change one important detail. Show the old quote and approvals becoming outdated. This is the central product demonstration.

1:50–2:20: Resolve the new revision from the maker's authenticated view. Export the current brief with matching quote, confirmation and discrepancy record.

2:20–2:40: Explain the server-side YouCam integration and state one measured evaluation result, with sample size. State the main limitation. End on the agreed brief.

The delivered illustration cannot be narrated as a real try-on. Until live integration is run, use it only to rehearse the workflow. A real recorded result should be labeled recorded and tied to its evidence record. Do not fake a maker interview, customer order, conversion number or runtime metric.
