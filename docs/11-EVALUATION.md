# Evaluation protocol

## Integration

Use 3–5 suitable permissioned garment references and consenting source images. Record attempted and successful jobs, latency, unit debit, category, output version and detail failures. Keep denominator and exclusions visible. A tiny sample does not validate support across all clothing or populations.

## Decision workflow

Ask a maker and 3–5 willing shoppers, if available, to complete a defined task without coaching: select a reference, identify one unresolved detail, review a quote, agree to it, and recognize an outdated agreement after a change. Measure completion, time, errors and misunderstandings. Record actual sample size and results.

## State integrity

Automated tests protect current-version agreement, new-quote invalidation, unresolved detail revocation, invalid currency/amount/option rejection and stale revision errors. Extend them when introducing permissions, quote expiry and field-level dependencies.

## Reporting

Report counts honestly: e.g. X of N participants completed the task without assistance, Y of Z previews required detail correction. Fill values only after testing. Avoid broad claims about reduced returns, clinical safety, color accuracy or manufacturing feasibility.

An evidence table should include claim, method, inputs, actual result, limitation and source artifact. Retain failed results privately when appropriate; do not hide them merely because they weaken the story.
